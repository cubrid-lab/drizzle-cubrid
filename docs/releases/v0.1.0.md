## v0.1.0 (2026-03-13)

Initial TypeScript Drizzle ORM dialect for CUBRID, backed by the Node.js CUBRID client.

### Compatibility

- Requires Node.js 18 or newer and a compatible Drizzle ORM and CUBRID client. Types and runtime behavior must be verified against the versioned dependencies in this tag.
- The initial development dependency pointed to a local client checkout; installability from a standalone published npm package was corrected in v0.2.1.

### Features

- Provide `drizzle()` integration and CUBRID table/column definitions through Drizzle ORM by @yeongseon
- Add query operations, schema builders and CUBRID-specific collection/monetary column support by @yeongseon

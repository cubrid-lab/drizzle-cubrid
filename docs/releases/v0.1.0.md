## v0.1.0 (2026-03-13)

Initial TypeScript Drizzle ORM dialect for CUBRID, backed by the Node.js CUBRID client. Import standard column builders such as `int` from `drizzle-orm/mysql-core`, or upgrade to v0.2.0 (see Compatibility).

### Compatibility

- Requires Node.js 18 or newer, with `drizzle-orm` and `cubrid-client` as peer dependencies.
- The package root's TypeScript declarations list the standard MySQL-compatible column builders (`int`, `varchar` and others), but neither the ESM nor the CommonJS build exports them, so importing them from `drizzle-cubrid` type-checks and fails at runtime; fixed in v0.2.0.
- The development dependency pointed to a local `../cubrid-client` checkout (contributors and CI only); v0.2.1 changed `package.json` to the published package, and the lockfile and CI stopped using the sibling checkout after v0.2.1.

### Features

- Provide `drizzle()` integration and the `cubridTable()` table builder through Drizzle ORM by @yeongseon
- Add query operations, schema builders and CUBRID-specific collection/monetary column support by @yeongseon

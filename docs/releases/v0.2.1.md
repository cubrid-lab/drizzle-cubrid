## v0.2.1 (2026-03-14)

Point the `cubrid-client` development dependency in `package.json` at the published package. The published library is unchanged from v0.2.0; no user action is needed.

### Compatibility

- The published `dist` files, `engines` and peer ranges are identical to v0.2.0; only `version` and the `cubrid-client` development dependency changed.
- The tagged `package-lock.json` and the CI and publish workflows still used a sibling `../cubrid-client` checkout, so `npm ci` at this tag fails without one; that requirement was removed after v0.2.1 ([3f815fe](https://github.com/cubrid-lab/drizzle-cubrid/commit/3f815fee), [be6709c](https://github.com/cubrid-lab/drizzle-cubrid/commit/be6709cf), [60474c2](https://github.com/cubrid-lab/drizzle-cubrid/commit/60474c2d))

### Bug Fixes

- Change the `cubrid-client` development dependency in `package.json` from `file:../cubrid-client` to the published `^1.0.0` ([13b0767](https://github.com/cubrid-lab/drizzle-cubrid/commit/13b0767a)) by @yeongseon
